Análisis de Métricas de Software y DevOps

Este repositorio contiene el proyecto de análisis estadístico de métricas DevOps. El objetivo principal es limpiar, explorar y visualizar los datos generados para obtener conclusiones accionables sobre el rendimiento de los equipos y la calidad del software.

Contenido del repositorio

Esqueleto.Rmd: Script de RMarkdown que contiene todo el código, la narrativa y la bitácora de prompts.
devops_metrics.csv: Conjunto de datos utilizado.
Reporte_Final.pdf: El documento exportado con el análisis completo y las gráficas.

Instrucciones de ejecución

Para reproducir este análisis desde cero:

1. Descarga o clona este repositorio en tu equipo.
2. Abre el archivo `Esqueleto.Rmd` utilizando **RStudio**.
3. Asegúrate de que el archivo de datos `devops_metrics.csv` se encuentre guardado exactamente en la misma carpeta que el archivo `.Rmd`.
4. En la barra superior de RStudio, presiona el botón **Knit** (Render). Esto ejecutará automáticamente todo el código y regenerará el reporte en formato PDF.
